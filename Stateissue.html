Setup & Data

Display Name

This name is saved with new messages and comments. It can be left blank. Changing it does not alter older entries.

Backup creates one file. Save that file to a flash drive. The program saves changes automatically on this computer, but a backup is the only second copy. Back up at least weekly.

One-time Firefox setup for automatic backups
1. Make a folder named StateIssue_Backups (for example on the C: drive).
2. In Firefox: Menu → Options → General → Downloads. Choose that folder, and uncheck "Always ask you where to save files."
3. Options → Privacy: do NOT let Firefox clear history when it closes.
4. Press TURN ON AUTOMATIC BACKUPS below and follow the questions.
5. Once a week, copy the newest file from that folder to the flash drive (right-click the file → Send to → your USB drive).

Recent Changes

Every saved change is logged with the date, the time, the configured display name (if set), and the computer it came from. The log records counts only, not inmate or personal names.
