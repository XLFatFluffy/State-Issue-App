Setup & Data

Display Name

Set a name for this browser so coworkers can tell who added or updated a record. A name is required to use the app; it is not a login or verified identity.

Report a Problem or Suggestion

Tell us what went wrong or what would make the app better. Point to the screen or button, and include a request ID—or a name or MDOC number if that helps us find the right record. Reports are shared with everyone who can open the app. You'll need a connection to send one; reports aren't saved offline.

Shared Feedback Inbox

Reports show up on every connected computer. Update the status as you review each one. Names shown here are workstation labels.

Back Up and Restore Data

Routine backups are SQLite snapshots saved on the host in the application's backups folder, not downloads on this workstation. Daily and monthly copies are automatic. Download a JSON export only when you deliberately need a portable copy. Keep a separate secure copy outside the host in case that computer fails.

Recent Changes

Saved-change logs are kept for seven days, then automatically deleted. They show the time, workstation name (if set), computer, and counts of records changed—not names or details. Older database backups may contain earlier log entries.

Export to Excel (CSV files)

These buttons download spreadsheets you can open in Excel. They may include names and other record details, so store them securely and remove them from shared computers when you're done.

Stock Targets & Reorder Alerts

Set the on-hand quantity you aim to keep and a separate reorder trigger. The app flags stock at or below the trigger and suggests how many units would bring it back to target. Set a value to 0 to disable that target or alert.
